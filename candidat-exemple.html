Candidat B (exemple fictif)

Baisse de 2 points des cotisations sociales salariales sur les bas salaires

Thème : Fiscalité

Résumé officiel : mesure présentée par le candidat comme un soutien direct au pouvoir d'achat des travailleurs modestes. Voir la source primaire (programme officiel).

Analyse d'impact croisé, par classe sociale

Classes populaires
Score : +2 / 2

Avantages

  • Hausse mécanique du salaire net pour les bas salaires
  • Effet visible dès le premier mois selon le calendrier annoncé

Risques

  • Financement du manque à gagner pour la Sécurité sociale non détaillé
Angle mort : le programme ne précise pas si la mesure est pérenne ou compensée par une autre recette.
Classes moyennes
Score : +1 / 2

Avantages

  • Effet partiel pour les salaires proches du seuil bas

Risques

  • Effet dégressif au-delà d'un certain niveau de salaire, seuil exact non communiqué
Angle mort : absence de simulation chiffrée pour les tranches intermédiaires du barème.
Classes aisées
Score : 0 / 2

Avantages

  • Aucun bénéfice direct identifié

Risques

  • Aucun risque direct identifié
Angle mort : mesure non applicable aux hauts salaires, sans effet direct mentionné dans le programme.
Retraités & inactifs
Score : 0 / 2

Avantages

  • Aucun effet direct identifié

Risques

  • Absence de mesure miroir pour les retraités mentionnée dans le programme
Angle mort : le programme ne traite pas explicitement du pouvoir d'achat des retraités dans cette mesure.
